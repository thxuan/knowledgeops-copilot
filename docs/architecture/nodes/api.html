02 / EXECUTION FLOW

代码是怎样一步步执行的？

  1. 01

    集中装配依赖

    create_app 加载并验证 Settings，构造摄取、切分、会话、向量、检索、RAG 和持久化 Agent 服务，放入 app.state。

  2. 02

    启动与关闭生命周期

    lifespan 初始化数据库，按配置启动摄取 worker；关闭时停止 worker 并取消本进程 Agent 协程。

  3. 03

    注入服务端身份

    get_identity 从 LOCAL_IDENTITIES 映射 user_id、tenant_id 和 audiences；路由用 Depends 接收，不能信任模型或文档声明身份。

  4. 04

    统一请求诊断

    中间件生成请求 ID、记录耗时和状态，异常处理器统一 AppError / 参数错误 / HTTP 错误响应。受保护响应禁止缓存。

请求经过什么
HTTP 请求 → request_context
→ Pydantic 请求校验 + get_identity
→ 路由 → 业务服务 → 仓储 / 模型
→ 响应或统一 error + request_id

04 / DESIGN BOUNDARIES

需要讲清的设计边界

本地身份不是生产认证

当前是测试身份头，没有接入真实单点登录或令牌验证。对外部署前需要替换认证入口。

缺少依赖时按功能失败

向量库或 Agent 库未配置时相关接口返回 503；不能把 /health 成功理解为所有模型和数据库就绪。

05 / TERMINOLOGY

专业术语 · 中英全名

中文 / 缩写英文全名在项目中的含义
API · 应用程序编程接口Application Programming Interface项目用 FastAPI 暴露文档、检索、聊天和 Agent 接口。FastAPI 是框架名，不是需要展开的缩写。
HTTP · 超文本传输协议Hypertext Transfer Protocol浏览器或客户端与 API 之间的请求响应协议。
DI · 依赖注入Dependency Injection路由通过 Depends 接收身份，create_app 组装服务，并允许测试替换模型客户端。
ACL · 访问控制列表Access Control Listdocument_access 保存文档到用户的授权；身份和租户由服务端映射。
JSON · JavaScript 对象表示法JavaScript Object Notation模型输出与工具参数的结构化格式；JSON Schema 是其结构约束描述。
