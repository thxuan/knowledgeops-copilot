02 / EXECUTION FLOW

代码是怎样一步步执行的？

  1. 01

    捕获切分快照

    index_document 读取当前 chunk_set_id；同模型配置下完整集合已存在时可复用。

  2. 02

    有界批量向量化

    按 batch_size 分批，有限 worker 并发请求；校验返回数量、维度和有限数值；瞬时错误在上限内退避重试。

  3. 03

    完整发布

    所有批次成功后再复核当前集合；publish 在 PostgreSQL 事务内写入整套向量并切换向量头。批次失败不会发布半套索引。

04 / DESIGN BOUNDARIES

需要讲清的设计边界

分阶段发布索引

PostgreSQL 文档头与 PostgreSQL 向量头分别维护；依靠当前集合校验和检索再授权避免返回旧集合。

索引算法与检索策略不同

exact / hnsw 是向量搜索方式；vector / hybrid / hybrid_rerank 是检索策略。模型与维度不能静默混用。
