40 个术语 · 中文含义 / 英文全名 / 项目用法

40 项
01

RAG · 检索增强生成

Retrieval-Augmented Generation

先检索本轮授权文档，再用证据生成回答；入口为 POST /chat。
#
02

LLM · 大语言模型

Large Language Model

通过适配器参与答案生成和工具选择，不能直接执行数据库操作。
#
03

API · 应用程序编程接口

Application Programming Interface

项目用 FastAPI 暴露文档、检索、聊天和 Agent 接口。FastAPI 是框架名，不是需要展开的缩写。
#
04

HTTP · 超文本传输协议

Hypertext Transfer Protocol

浏览器或客户端与 API 之间的请求响应协议。
#
05

JSON · JavaScript 对象表示法

JavaScript Object Notation

模型输出与工具参数的结构化格式；JSON Schema 是其结构约束描述。
#
06

模式约束

Schema / JSON Schema

定义必填字段、类型、枚举和额外字段规则；Pydantic 执行运行时校验。
#
07

文本分块

Text Chunk / Chunking

把清洗后的正文切成带来源位置的片段；当前 size 和 overlap 的单位是字符。
#
08

向量嵌入

Embedding

将片段或问题编码成数值向量；模型、维度和距离函数必须保持一致。
#
09

HNSW · 分层可导航小世界图

Hierarchical Navigable Small World

pgvector 的近似向量索引；本项目也保留精确搜索作为基线。
#
10

BM25 · 最佳匹配 25

Best Matching 25

关键词相关性排序；当前使用中文二元字组与英文标识符分词，仅统计授权语料。
#
11

RRF · 倒数排名融合

Reciprocal Rank Fusion

对每一路的 1 / (常数 + 排名) 求和，融合向量和关键词结果；不直接相加原始分数。
#
12

重排序

Reranking

对召回候选再次排序；已实现，可选启用，冻结的 hybrid 配置关闭它。
#
13

前 K 个结果

Top K Results

candidate_k 控制候选池，top_k 控制最终结果；两者不是同一层的参数。
#
14

ACL · 访问控制列表

Access Control List

document_access 保存文档到用户的授权；身份和租户由服务端映射。
#
15

词元

Token

模型处理和计费的文本单位；项目的 UTF-8 字节预算是保守估算，不等于真实账单词元。
#
16

提示词

Prompt

模型的规则与任务输入；提示词约束不能代替服务端权限、校验和事务。
#
17

来源引用

Citation

绑定文档、版本、chunk_set_id、chunk_id 与位置；读取时重新检查当前权限。
#
18

事实结论

Claim

RAG 输出中的单条结论及其 citations；服务端汇总成 answer。
#
19

智能体

Agent

在有界循环里依据中间结果继续选择工具；当前为自写单 Agent 执行器。
#
20

工具调用

Tool Calling / Function Calling

模型输出工具名与参数，服务端执行并通过 tool_call_id 关联回填结果。
#
21

检查点

Checkpoint

持久化运行消息、阶段、预算与结果，供同一个 run_id 恢复执行。
#
22

租约

Lease

有时间期限的执行权；租约 token 隔离已失去执行权的旧执行器。
#
23

幂等性

Idempotency

相同请求键复用任务，相同 action_id 不重复创建工单。
#
24

数据库事务

Database Transaction

将本地工单、动作结果和任务回填一并提交或回滚，避免只成功一半。
#
25

SQL · 结构化查询语言

Structured Query Language

业务工具执行预定义的参数化查询，不接受模型生成的任意 SQL。
#
26

JSONB · 二进制 JSON 数据类型

Binary JSON

PostgreSQL 用来保存 Agent state、参数与结果的数据类型。
#
27

SSE · 服务器发送事件

Server-Sent Events

服务端单向事件流；通过持久化事件 ID 支持补发，不创建新任务。
#
28

TTFT · 首词元时间

Time to First Token

供应商首个输出词元的时间；当前 Agent 文本在完整校验后分段发送，不能算真实 TTFT。
#
29

MRR · 平均倒数排名

Mean Reciprocal Rank

对首个相关结果排名取倒数再求平均，用于衡量相关证据出现得是否靠前。
#
30

前 K 项召回率

Recall at K

在预先标注的相关来源中，前 K 个结果命中了多少；无答案样本单独统计。
#
31

第 95 百分位延迟

95th Percentile Latency

95% 样本的延迟不超过此值；P50 为第 50 百分位，小样本尾部估计不稳定。
#
32

提示词注入

Prompt Injection

用户、文档或工具结果试图改变系统行为；检测告警与实际授权防线分开。
#
33

UTF-8 · Unicode 转换格式 8 位

Unicode Transformation Format — 8-bit

文本编码；预算按编码后的字节数估算，因此字节数、字符数与 Token 数不同。
#
34

SHA-256 · 安全散列算法 256 位

Secure Hash Algorithm — 256-bit

用于文件哈希、版本标识、审批参数摘要；摘要用于绑定内容，不是加密。
#
35

DI · 依赖注入

Dependency Injection

路由通过 Depends 接收身份，create_app 组装服务，并允许测试替换模型客户端。
#
36

MCP · 模型上下文协议

Model Context Protocol

计划中的可选工具接入协议，当前代码没有实现 MCP 服务。
#
37

CI · 持续集成

Continuous Integration

计划 Day 13 的自动化检查；当前有 pytest 测试，未发现 CI 工作流。
#
38

OCR · 光学字符识别

Optical Character Recognition

把扫描图片转为文本；当前摄取只接受 Markdown/TXT，未实现 PDF/OCR。
#
39

执行轨迹

Execution Trace

记录工具调用、状态、耗时及结果；日志用于诊断，检查点和事务负责恢复与副作用。
#
40

指数退避与抖动

Exponential Backoff and Jitter

瞬时错误有界重试，逐步增加等待并加入随机扰动，避免同时重试。
#
