# 会话界面

取消任务、暂不提交提案或关闭过期预览成功后，清空当前消息区和草稿，解除旧会话上下文并返回欢迎页；任务和问答审计记录仍保留在“评测与记录”，已创建的工单不受影响。取消失败不清空。缓存恢复时，已取消的最后任务不再重新展示为当前对话。

自由记录按会话 → 轮次 → 尝试展示；失败、停止与手动重跑保留独立尝试，Agent 的轮询与工具步骤不会增加轮数。测试集入口与自由会话入口分别统计，未标注自由问题不计作来源召回率为零。旧记录可按已有会话 ID 分组，缺少快照时禁用原上下文重跑。

服务端在问答运行前保存按租户、用户隔离的不可变历史检查点，包含实际供检索与上下文构建使用的历史提问和摘要。重跑必须使用原问题，仍重新检索并检查当前证据权限；不调用任务路由，不追加或改写原会话。调整预算可能改变实际选用的历史条目，运行详情保留选用 ID。只有原问题、历史指纹、身份与知识库版本均匹配时，才提示对比条件一致。

新增后端需重启才支持历史快照；运行中的旧服务仍可使用前端会话分组，但原上下文重跑保持禁用。模型和连接配置可能仅保存在服务内存中，重启前需由用户准备恢复。旧记录不会补造快照或重试关系。

会话页沿用项目绿色、字体和原生 HTML/CSS/JavaScript，以阅读内容、引用依据与审批操作为主要信息层级。

浅色玻璃主题集中在导航、外层卡片和弹窗：静态灰绿渐变背景、半透明白色表面、细亮边与轻阴影构成层次。正文区、输入框和表格保持较高不透明度。800px 以下关闭大面积卡片的背景模糊；不支持背景模糊、偏好减少透明或提高对比度时，使用更实的表面颜色。

2026-10-17 更新：各页使用 `app/web/ui-theme.css` 共享表面、颜色、圆角、控件和动效变量。主导航按会话、知识库、我的工单、业务状态、连接设置排列。会话的运行参数、运行详情和 API 文档收进调试工具；模型连接入口与模式选择集中在输入框底部。欢迎区限宽，示例只填写草稿；发送前仍需用户确认。

消息区使用独立的底部跟随状态。滚轮、触摸和翻页键离开底部后暂停追随，距底部超过 120px 时显示“回到最新”；重新进入 40px 范围恢复跟随，用户输入后 150ms 内不强制定位。发送新消息、主动回到最新和新建会话会重置跟随。流式预览、最终回答及 Agent 结束使用同一规则。

知识问答进入检索、生成、复查或校验阶段后提供“停止生成”；意图分配与最终保存阶段不提供该按钮。停止会中断当前 SSE 接收，未校验的预览不转为正式答案，草稿保留；已持久化 Agent 的取消仍使用原任务接口。失败或停止后可手动重试，界面不会自动发起模型请求。

1100px 以上直接点击回答引用时，原文使用非模态侧栏，可与答案对照；从其他模态窗口打开或在窄屏打开时使用模态抽屉。读取继续调用原引用权限与版本检查接口；重复切换引用和关闭抽屉后，旧请求不能覆盖新来源。Escape 关闭后恢复到引用触发按钮。来源列表支持折叠，首次在 800px 以下生成的回答默认收起来源。

本轮使用项目外的隔离 HTTP/SSE 数据进行界面验收，未调用供应商或提交真实工单。已检查回答完成、连接失败与手动重试、停止接收、来源抽屉、工单编辑后重新确认、知识库原文/切块切换与设置未保存标记。会话、知识库、设置、业务与工单页在 320、390、768、1280、1920px 宽度下检查布局；此记录不替代真实模型与数据库的端到端验收。

任务结束后默认折叠处理记录；待审批提案明确显示创建范围，编辑后仍需确认。知识库将切分参数收进“切分与索引设置”，提供原文与切块预览切换。连接设置分别标记未配置、已保存、有未保存修改和检测结果；检测通过不代表草稿已保存。

- 会话页使用视口内的应用布局，只有消息区滚动；评测视图单独滚动。输入区从单行起步，随草稿增长至 148px，避免挤占阅读空间。
- 所有屏宽统一使用上下布局：回答或工单预览在前，真实引用来源、工具处理记录及任务详情紧接其后，与正文同宽；保留折叠查看、所有依据与审批操作。
- 发送者、任务状态和工单动作分层展示。任务编号、事件和原始工具结果仍可展开查看。过期预览显示明确状态，审批规则保持原样。
- 回答下方的来源列表按文档和版本分组，点击仍沿用原文授权检查。原文内逐条引用不合并，保留精确引用入口。
- 会话布局在 `app/web/conversation.css` 中限定于 `workbench-page`；共享主题同步应用到知识库、连接设置、业务与工单页，业务请求与授权边界仍由原有接口处理。

界面检查包括真实页面只读浏览，以及复用组件的隔离布局、编辑和焦点检查。隔离示例不调用模型或写入业务数据。静态前端变更不需要重启服务。

验证记录：320、390、768、1280、1920px 屏宽未见整页水平溢出或外层纵向滚动；正式页参数弹窗可用 Escape 关闭并返回触发按钮，引用原文读取成功，评测视图可切换。隔离组件中的工单修改可保存回预览并保留待确认状态。关键正文、辅助文字、状态和主按钮的颜色组合计算对比度均大于 4.5:1；未声称完成整页无障碍审计。

过期预览使用「关闭过期预览」调用现有任务取消接口，不再向审批接口发送过期拒绝。拒绝请求在传输途中到期时，也仅回退为取消同一任务；确认创建或修改过期时仍报错，并刷新过期状态。终态任务即使在旧服务端响应中保留 pending 字段，界面也不再显示可操作审批卡片。此修复只涉及静态前端，无需重启或操作已有工单。

顶部导航与「当前身份」由 app/web/app-header.css 统一管理，选项固定为工程师、普通员工、IT 支持，保留原身份 ID 和跨页会话存储。模型设置与运行参数保留在会话工具栏。稳定滚动条占位避免不同页面间身份控件横向跳动。
