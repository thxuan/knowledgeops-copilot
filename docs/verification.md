## 指标口径

- 来源 Recall@K：已取回必要来源占标注必要来源的比例，不等于答案准确率。
- MRR：首个相关结果排名倒数的平均。
- 章节精确率与字符覆盖：需要与当前正文坐标一致的章节标注，没有坐标时不计算。
- 跨文档完整性：检查需要多份来源的题目是否取回所有必要来源，不代表生成答案涵盖所有条件。
- 引用有效性：引用来自当前授权集合、可定位到有效版本，不代表引用支持该句全部语义。
- 答案正确性：需人工或受审查的语义评审；未评审保持待评审，不能按请求成功自动记为正确。
- Agent 成功：结果符合预期且最终业务状态正确，权限、审批和幂等约束均成立；模型自称成功不算证据。

自由提问没有标注，显示耗时、用量和证据等运行信息；带标注的测试集才提供对应质量指标。

## 重新验证

从项目根目录运行离线工程回归：

```sh
python scripts/run_tests.py -q
node --test tests/unit/*.mjs
```

测试在独立随机 schema 中准备数据，结束后只清理测试空间；不调用付费模型。测试替身仅位于 tests，运行时只使用真实模型或显式未配置状态。

真实模型评测先固定模型、切块、检索、生成采样与提示词配置，通过工作台导入 JSONL 或运行 `scripts/evaluate_rag.py`。只在开发集选择参数，保留集不用于反向调参。评测记录代码和数据指纹，源码变化后旧冻结记录不能自动成为新版本成绩。

## 尚未验证的范围

完整真实模型答案正确率、引用语义支持率、真实模型批量 Agent 成功率、生产认证、云端并发和长期稳定性没有当前版本的完整验收成绩。SSE 发送已校验文本事件，未验证上游 Token 流式输出或真实 TTFT。历史保留集和跨文档试验成绩已归档，未移用为当前版本质量结论。

完整运行数据库、原始模型消息、个人连接信息和密钥留在本地。公开仓库的 ko_samples 备份只包含审查后的虚构样例及对应真实向量，排除会话、运行日志和旧测试集合。
