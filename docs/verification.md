## 指标口径

- Recall@K：取回有标注的相关来源/区间占必要来源的比例，不是“取回多少向量”，也不等于答案正确率。
- MRR（Mean Reciprocal Rank，平均倒数排名）：首个相关结果位置的倒数的平均。
- 引用有效性：引用属于当前授权集合且可定位；不等于该句完全被证据支持。
- 答案正确性/完整性：人工或受审查的标注判断事实、条件和必要要点，未完成复核的字段保持 null。
- Agent 成功：任务符合预期且最终业务状态正确，拒绝/审批/权限边界未被绕过；自然语言自称成功不算证据。

真实保留集已知失败 X004：需要的章节或约束未完整进入最终答案，因此不能把 Recall=1 宣传成“答案准确率100%”。真实模型批量 Agent 质量、修复后的工单最终措辞、云端并发和真实 TTFT 尚未完成验证。SSE 文本在回答校验后才发送。

## 如何重新验证

用 `python scripts/run_tests.py` 运行离线完整回归。旧 Fake 演示已归档，运行时仅支持真实模型；真实评测使用工作台导入带来源标注的 JSONL 测试集，或配置真实模型后运行 `scripts/evaluate_rag.py`。

真实模型测试前固定模型、切块、检索与提示词配置，只在开发集选择参数；保留集不得反过来调参。评测会记录代码/数据哈希，旧 freeze-from 无法直接应用到改变了源码的新版本。重新运行并完成评审后才能更新对外结果。

运行输出、数据快照、原始模型消息和个人连接信息默认留在本地，公开仓库仅保留汇总，不包含完整运行数据库。
