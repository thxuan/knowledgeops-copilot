# 统一会话工作台

当前入口：[http://127.0.0.1:8000/](http://127.0.0.1:8000/)。

## 启动与模型

在已有真实模型配置的终端执行 `python scripts/workbench.py`。它保留现有环境变量、数据库和向量索引设置，不会像离线演示脚本那样覆盖模型配置。也可以直接运行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`。

“连接设置”页的生成模型配置支持 Base URL、模型名称、API Key，以及实际的输入/输出单价（每百万 tokens，同一币种）。复用项目的 CompatibleGenerationClient 和 CompatibleAgentModel。连接测试会进行一次小型 JSON 请求，不代表供应商工具调用能力已经验证。

工作台不提供 Fake 选项，未配置真实模型时不能发送。原有离线测试替身仍用于自动化回归，不会作为工作台问答的回退模型。Embedding 与 Reranker 可在“连接设置”页配置和测试，修改聊天模型不会更换索引。

密钥只保存在当前服务进程内存中，不写磁盘、不返回浏览器、不进入实验导出。Base URL 不变时可以留空保留已有密钥；更换地址必须重新输入。服务重启后使用环境配置或重新填写。配置面向这个本地服务，所有模拟身份共用；不是多租户部署的管理入口。

Agent 沿用现有费用预算：填写两项模型单价后启用。存在未结束任务时禁止更换模型；重启后可恢复任务原来的模型与预算策略。

知识问答也使用真实聊天模型生成答案，自动模式另有模型意图识别；语义检索使用 Embedding 模型。输入/输出单价是 Agent 本地费用预算的配置，不是模型调用开关。首次只启用问答可不填单价，但供应商仍按账户计费规则收费；启用 Agent 或更换已启用 Agent 的模型时必须填写两项真实单价。

## 统一会话

一个输入框提供“自动 / 仅知识问答”。自动模式使用真实模型结合当前用户拥有的会话历史判断意图：文档问题走原问答检索、引用与评测；查询业务状态、计算和创建工单等请求走持久化 Agent。

Agent 会接收前文，工具调用、审批卡片和结果显示在同一聊天流中。任务结束后结果写入同一服务端会话，可继续补充说明。写操作仍通过明确的审批按钮提交，聊天里的“批准”文字不能替代审批。未结束任务需完成或取消后再开始下一轮。Agent 的检索/模型执行预算仍采用其服务端配置，左侧运行参数用于知识问答。

会话历史用于意图和指代理解；知识事实仍需要本轮授权证据。历史传递前重查原文权限。任务重复请求通过 request_key 复用原 run，不会重新创建工单。

页面刷新可重新显示当前身份未结束的任务。评测结果自动保存在浏览器 IndexedDB，详见下方缓存说明；服务端仍保留会话与 Agent 记录。

## 参数与指标

“运行参数”侧栏提供快速问答、均衡检索、跨文档分析三种预设，以及各路候选数、RRF 保留数与证据上限。关闭通道会收起所属数值，RRF 常数和 HNSW 参数默认折叠。Temperature / Top-P 提供滑块与精确输入；模型采样 Top-K 尚未接入现有适配器。

保留来源召回、章节精确率、跨文档完整召回、阶段耗时、token 用量、原文查看、A/B、批量开发集、人工评审和 JSON 导出。自动分流耗时单列并计入总耗时。自由提问没有标注答案，质量指标保持未评测；检索质量不等于答案正确性。

## 接口

- `GET /workbench/model`：配置状态，无密钥内容。
- `POST /workbench/model/test`：测试指定真实接口。
- `PUT /workbench/model`：保存并启用当前进程模型配置。
- `POST /workbench/message`：统一会话入口，返回 question 或 agent。
- `POST /workbench/chat`：直接问答入口，供批量评测与重跑使用。
- 现有 `/agent/{run_id}`、审批、取消、恢复接口继续负责持久化任务。

接口均要求现有本地身份请求头。文档、Agent 权限和审批约束沿用原实现。


## 导入 JSONL 测试集

运行模式默认“自由提问 · 不计算质量指标”。选择“导入测试集（JSONL）…”后，选择题目文件和可选的章节坐标文件，点击“校验并导入”。导入本身不调用模型。预览会显示题目数、来源/坐标/答案标注数，并可按 split 选择测试范围；点击“开始评测”后才调用模型。

最小格式（UTF-8，每行一个对象）：
```json
{"question_id":"Q001","question":"VPN 如何配置？"}
```
question 必填，question_id 可省略自动生成。支持现有 eval_data/questions.jsonl；可配合 eval_data/day4-source-spans.jsonl，或将坐标列表放进每题 source_spans。导入窗口可下载包含内嵌坐标的开发集示例。每文件最多 2 MB，每集 1–200 题。

expected_sources 每项必须有 version 和 document_id 或 source。使用实际入库文档 ID、source 路径，或项目样例的逻辑文档 ID。文档必须已入库、版本匹配且当前身份有权限。没有来源标注时，召回未评测；没有章节坐标时，章节精确率和字符覆盖未评测；有答案要点也仍需人工评审。标注不会传入生成模型。

测试集存于服务端内存并绑定导入身份，每个身份保留最近 8 个。服务重启后需重新导入。批量测试逐题使用独立上下文，固定开始时的参数，服务端模型/索引配置变化时中止。停止按钮完成当前题后停止后续题。结果提供逐题记录、最近批次汇总、失败记录及 JSON 导出。测试过程不会替换自由会话上下文。当前批量入口针对 RAG 问答，不执行 Agent 写操作。


## 知识库与连接管理

工作台新增 `/knowledge`（知识库）与 `/settings`（连接设置）。知识库先展示当前身份可见的现有文档、解析状态、切块数与当前集合的索引状态；支持 Markdown/TXT 上传、全文与切分预览、显式构建索引、上传者修改访问权限、失败解析重试。预览不修改数据库；索引构建先暂存新切块并完成全部向量请求，再在同一个事务中切换切块和向量指针。失败保留原索引。当前文件大小上限沿用服务端配置，默认 1 MB。

连接设置支持 PostgreSQL 主机、端口、数据库、用户、密码与 schema；检测后列出真实模型集合，选择时填入已记录的模型、地址、维度。已有集合严格校验模型签名，更换模型或维度需使用新集合。当前版本连接已经初始化的 schema，不提供数据库建库操作。Embedding、Rerank 均提供真实请求测试。Rerank 使用完整 `/reranks` 接口地址；配置完成后在会话参数中按次开关。生成模型独立保存。

设置为本地服务共享的内存配置；GET 接口不返回密钥，浏览器不持久化密钥。新服务地址不会自动沿用旧密钥。重启后从环境变量恢复或重新输入。切换连接拒绝进行中的 HTTP 请求和未结束的真实 Agent 任务，并停止旧解析 worker 后替换服务依赖。Agent 业务查询保留原有只读连接身份；跨数据库时不会自动改用可写账户。

启动脚本在没有显式数据库环境变量时优先选择本地已存在的 `ko_samples` schema。设置页会优先展示该 schema 的已有真实集合配置；仍需填写有效 Embedding Key 并应用，才可使用语义检索。不会重新导入已有样例文档。

批量评测开始前检查模型配置和当前身份的可检索文档数；若为空，阻止开始并提示检查 schema、集合、索引或权限。服务端也拒绝没有可检索文档的导入测试集请求。运行指纹包含数据库与 schema，连接变化后停止后续题。就绪检查验证配置与索引状态，服务连通性由各自的“测试”按钮验证。


## 浏览器本地评测记录

会话与评测通过 IndexedDB 自动保存导入的 JSONL、运行参数、逐题结果、失败记录、批次进度、人工评审与 A/B 选择。缓存按演示身份、数据库主机/端口/库名/schema 和索引集合隔离，仅供当前浏览器使用，不保存连接密码或 API Key。导航顺序为连接设置 → 知识库 → 会话与评测。切换页面、刷新后恢复当前空间记录；历史回答为本机快照，原文查看仍需服务端授权。

运行中的批次恢复为“已中断”，不会自动调用模型。点击“继续中断批次”会重新校验导入文件（兼容服务重启），保持原批次参数和运行指纹，并跳过已有成功/失败记录的题目。离开页面时尚未返回的请求可能已在服务端执行，手动继续可能再次调用该题；界面会明确提示。配置指纹不同则不能混入旧批次，需要恢复原配置或开始新批次。

可通过“清空本地记录”删除当前身份与知识库空间的缓存。浏览器清理站点数据、隐私模式或存储额度不足仍会影响保留，重要结果可继续导出 JSON。此功能不在后台持续运行离开的评测，也不持久化 Agent 审批状态到浏览器。


## 界面布局（2026-10-14）

“会话与评测”包含两个视图：会话用于自由提问和 Agent 任务；“评测与记录”用于导入 JSONL、运行批次、比较与导出。切换视图保留草稿和已导入测试集，运行中禁止切换。

“运行参数”打开参数侧栏；“运行详情”查看最近选中的答案、证据与指标。点击运行记录中的题号可查看该条详情。批量评测输出只进入运行记录，不追加到自由会话。历史缓存继续按身份、数据库和集合隔离。


## 批量上传与索引

知识库页面支持一次选择 1–100 个 Markdown / TXT 文件，每批合计最多 50 MB，单文件大小受服务端配置限制。上传后逐份等待解析，逐项显示结果。上传不会自动调用 Embedding；解析完成后勾选自己上传的文档，点击“批量构建索引”，统一设置切分策略、大小和重叠。

批量构建默认跳过当前集合已有的有效索引，即使本次切分参数不同。要应用新切分参数，显式勾选重建。每份文档仍按服务端 batch_size 分批计算向量，并在成功后一起发布切块与索引；失败不会替换旧的可用索引。

任务按文档顺序执行，可停止后续任务、继续未处理项或仅重试失败项。运行时需保持页面打开：队列保存在当前页面内存中，刷新或关闭会丢失待执行队列，已上传文档与已发布索引保存在数据库。上传解析重试沿用原任务回执，不重复上传。当前请求不会因点击停止而中断。队列固定身份与连接配置，检测到配置变化后停止，需刷新页面后重新选择文档。

## 自由会话的流式回答

自由会话使用 POST /workbench/message/stream（自动模式）或 /workbench/chat/stream，通过 SSE 接收处理阶段和最终结果。批量评测保留原有独立请求和记录格式。

知识问答向供应商发起 stream=true 请求。服务端接收完整输出，并完成适用条件、引用校验及持久化，期间界面显示处理阶段。前端确认最终结果且流正常结束后，逐字展示已校验正文，再呈现引用按钮和运行指标；不展示草稿或复查中的正文。显示动画不触发第二次模型调用，最长约 2.4 秒，减少动态效果偏好下直接显示全文。

上游截断、超时、权限校验失败或连接中断不会把未校验正文保存为成功回答。生成期间连接断开会取消该问答的上游工作；配置切换在整个流式请求结束前被阻止。流式接口不自动降级成第二次付费生成请求；供应商需支持兼容的chat-completions SSE及stream_options.include_usage。

Agent任务仍使用持久化执行和工具进度卡片，审批写入规则不变；该改动没有将Agent原始工具调用或未经校验的最终JSON当作逐token答案显示。

本次通过合成SSE及测试替身做离线验证，未调用用户模型、Embedding或运行真实Agent任务。启动服务后，界面配置的模型密钥仍需按现有内存配置方式填写。


### Agent 检索的 Embedding 单价

在「连接设置 → Embedding 与索引集合」填写每百万 tokens 的实际单价，并点击「应用连接配置」。币种与回答模型的输入、输出单价及任务费用预算保持一致。仅知识问答可留空；Agent 调用知识检索时会先预留 Embedding 费用，未配置时报 UNPRICED_TOOL，该轮所有工具均不执行。业务状态单独查询不要求此单价。修改单价不改变集合签名，无需重新切分或构建索引。

设置应用后，失败任务仍保留为历史记录；请重新发起任务验证。单价与密钥随连接配置仅保留在服务端内存；部署时也可使用 KNOWLEDGEOPS_EMBEDDING_COST_PER_MILLION_TOKENS 提供单价。
