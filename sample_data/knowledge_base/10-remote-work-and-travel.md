# 远程办公与出差网络安全指南

## 1. 远程办公

访问内部资源必须使用公司管理设备和 TideLink。家庭路由器应使用 WPA2 或 WPA3、修改默认管理密码并安装厂商仍支持的固件。不得为方便同住人员而共享公司设备。

视频会议中处理 L3 信息时，应使用耳机并确认屏幕共享范围。离开座位时锁屏；在共享空间避免让无关人员看到屏幕。

## 2. 公共网络

机场、酒店和咖啡店网络可能伪造登录页。确认网络名称，关闭自动加入和本地文件共享。完成门户登录后再连接 TideLink。若网络要求安装未知证书或管理描述文件，应立即停止并改用手机热点或其他可信网络。

公共网络不改变数据分类要求。VPN 保护传输路径，但不会让未授权的应用、个人设备或接收者变得合规。

## 3. 境内外出差

出发前至少 3 个工作日提交出差 IT 检查，说明国家或地区、时间和需要访问的系统。IT 会根据风险提供旅行设备、限制本地数据或调整认证方式。不要在边境或检查场景下自行删除审计代理。

前往高风险地区时可能发放临时旅行设备。旅行设备只同步必要数据，归还后由 IT 擦除。员工不得将公司设备交给他人保管或借用。

## 4. 设备遗失和扣留

设备遗失、被盗或脱离本人控制时，立即拨打 7700，报告资产编号、最后位置和时间。不要等待找回结果后再上报。使用其他设备登录 OneGate 终止活动会话；远程擦除由安全团队判断。

## 5. 受限行为

禁止使用个人 VPN、匿名代理或远程桌面绕过公司地域和安全控制。禁止在网吧或酒店公共电脑登录 OneGate。无法正常连接时应使用已批准的备用方式或联系服务台。
