# 工程环境与生产访问管理

## 1. 环境分级

工程环境分为开发（DEV）、预发布（STG）和生产（PRD）。DEV 可使用脱敏或合成数据；STG 默认只允许脱敏数据；PRD 包含真实业务数据，访问遵循最小权限和全程审计。

## 2. 标准访问

工程师完成安全培训并加入对应项目组后，可获得 DEV 的基本访问。STG 访问需要直属经理和系统负责人批准，有效期最长 90 天。PRD 不授予长期个人管理员权限，必须按具体任务申请临时访问。

PRD 临时访问要求：

- 有关联的变更单或 P1/P2 事件单。
- 直属经理与当班服务负责人双重批准。
- 最长有效 2 小时，到期自动撤销。
- 通过受管设备、TideLink VPN 和堡垒入口访问。
- 会话命令和文件传输接受审计。

批准只确认业务必要性，不覆盖设备合规、数据分类或当下账号状态。批准后若权限被撤销或设备变为不合规，执行时必须重新拒绝。

## 3. 数据库访问

生产数据库默认只读；写操作通过受审查的变更脚本执行。禁止在个人终端保存生产数据导出。排障查询必须限制字段和行数，涉及 L4 数据时使用专用审计工具。模型、自动化脚本和普通员工不能自行生成并执行任意 SQL。

## 4. 密钥和令牌

应用密钥存放在批准的密钥库中。个人访问令牌最长 30 天，必须限定权限范围。发现密钥提交到代码仓库时，应立即撤销并轮换；从 Git 历史删除字符串不能使旧密钥恢复安全。

## 5. 紧急访问

P1 事件可使用“紧急访问”流程，但仍需要事件指挥官批准并记录原因。紧急访问最长 60 分钟，事后 1 个工作日内完成复核。紧急不等于免审计，也不允许共享账号。

## 6. 访问复核

系统负责人每季度复核 STG 和项目组权限。临时 PRD 权限由系统自动到期。转岗人员应在生效当日撤销不再需要的工程权限，不能等到季度复核。
