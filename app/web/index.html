只有 question 也可以导入，缺失的题号自动生成。expected_sources 使用 document_id 或 source，并填写 version；来源需已入库且当前身份可访问。expected_answer_points 用于人工评审，source_spans 用于章节精确率和覆盖率。支持现有 questions.jsonl 与 day4-source-spans.jsonl。
