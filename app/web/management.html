    数据库与空间
    连接 PostgreSQL，选择已经初始化的知识库 schema。
    

    Embedding 与索引集合
    先选已有集合，其模型签名将自动填入下方。
    Agent 查阅知识库前需要单价来检查费用预算。请按服务商实际计费填写，与回答模型单价使用同一币种；仅知识问答可留空。修改单价无需重建索引。
    测试会发起一次真实请求。更换模型或维度请使用新集合，并重新构建索引。
    

    Rerank 可选
    配置后，可在会话参数中按次启用重排。
    

    应用数据库、Embedding 与 Rerank 配置。

    回答与任务模型
    独立保存；不会更改 Embedding 配置。
    启用 Agent 时需填写真实单价，以执行费用预算。仅知识问答可留空。
    

    上传文档
    一次可选择 1–100 个 Markdown/TXT 文件，逐个上传和解析。上传不会调用 Embedding，完成后勾选文档构建索引。
    批量构建索引
    默认跳过当前集合的有效索引，即使上方切分参数不同。需要应用新参数时请勾选重建。各文档独立提交，单个失败不影响其他文档。
